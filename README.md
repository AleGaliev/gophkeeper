# GophKeeper

**GophKeeper** — это безопасное хранилище конфиденциальной информации, разработанное на языке Go.  
Проект состоит из двух компонентов: **сервера** и **клиента**, объединённых в единую систему с использованием gRPC и HTTP API.

---

## 📦 Возможности

- Хранение зашифрованных данных:
    - Текстовые данные (например, логины/пароли)
    - Двоичные данные (например, файлы)
    - Банковские карты
- Аутентификация пользователя
- Шифрование данных на стороне клиента
- Поддержка RSA-ключей для безопасного обмена ключами
- Миграции базы данных с помощью `goose`
- Настройка через CLI и переменные окружения

---

## 🛠 Архитектура

### Сервер (`server`)
- Реализует gRPC и HTTP серверы
- Использует PostgreSQL в качестве основного хранилища
- Обрабатывает запросы от клиентов, проверяет аутентификацию, управляет данными

### Клиент (`client`)
- Локальное приложение для взаимодействия с сервером
- Выполняет шифрование/дешифрование данных до отправки/после получения
- Поддерживает CLI-интерфейс

## ⚙️ Конфигурация

### Сервер

| Флаг / Переменная окружения       | Описание                             | По умолчанию     |
|----------------------------------|--------------------------------------|------------------|
| `--log-level` / `GOPHKEEPER_LOG_LEVEL`     | Уровень логирования                  | `INFO`           |
| `--http-port` / `GOPHKEEPER_HTTP_PORT`     | Порт HTTP-сервера                    | `:8080`          |
| `--grpc-port` / `GOPHKEEPER_GRPC_PORT`     | Порт gRPC-сервера                    | `:8081`          |
| `--db-dsn` / `GOPHKEEPER_DSN`              | DSN для подключения к PostgreSQL     | —                |
| `--key` / `GOPHKEEPER_KEY`                 | Секретный ключ приложения            | —                |

### Клиент

| Флаг / Переменная окружения       | Описание                             | По умолчанию               |
|----------------------------------|--------------------------------------|----------------------------|
| `--addr` / `GOPHKEEPER_GRPC_ADDR`        | Адрес gRPC-сервера                   | —                          |
| `--user` / `GOPHKEEPER_AUTH_USER`        | Имя пользователя                     | —                          |
| `--password` / `GOPHKEEPER_AUTH_PASSWORD`| Пароль                               | —                          |
| `--key-path` / `GOPHKEEPER_PRIVATE_KEY`  | Путь к приватному RSA-ключу          | `~/.gophkeeper/id_rsa`     |
